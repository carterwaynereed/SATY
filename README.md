# Generated dashboard observations

Updated by the main-branch dashboard workflow. Source code and manual Unusual Whales inputs live on main. Do not store credentials or private lessons here.

`market.json`, `tv-evidence.json`, `latest.json`, `evidence.json`, `uw.json`, `learning.json`, `eod-review.json`, `health-alarms.json`, `changelog.json` and `challengers.jsonl` are the shared public JSON bundle consumed by the Saty+ home and the optional Pages mirror. They are committed together; consumers must still validate timestamps and match the snapshot evidence ID to the evidence statistics ID.

`latest.json` is a periodic snapshot. `state/` preserves first-observed events and later outcomes for research. Modeled entries are not executed trades or certified real-time forward signals.
